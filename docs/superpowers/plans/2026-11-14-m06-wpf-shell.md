# M06 WPF Shell Implementation Plan

**Goal:** Deliver the single-window Dashboard/Overlay shell, tray display state, and Guild Quest Board design foundation without implementing M07/M08 feature content.

## Scope map

- Presentation state: `ShellDisplayMode`, `OverlayMode`, `ShellViewModel`, commands.
- Window behavior: one `MainWindow`, `WindowModeController`, close interception, explicit exit.
- Visual foundation: WPF resource dictionaries, Guild Valley static background, accessible foreground contrast.
- Packaging: compile the approved background into the WPF application.
- Tests: shell mode transitions and pause-before-exit ordering.
- Documentation: mark only M06 complete after all verification gates pass.

## Explicit boundary

- M06 models `HiddenToTray` and hides the window, but the native tray icon/menu remains M10 work.
- Dashboard data binding belongs to M07; Overlay task/Pomodoro controls belong to M08.
- Ambient and mascot animation remains M11 work.

## TDD sequence

1. Add shell tests for default state, mode switching, hidden state, service preservation, and pause-before-exit.
2. Run the focused tests and confirm they fail because the shell API is absent.
3. Add the smallest shell state/command implementation that passes the tests.
4. Add the window controller and WPF visual resources; keep code-behind limited to window events.
5. Run Impeccable UI detection, build with warnings as errors, and run all tests.
6. Update `TASKS.md`, inspect the diff, and commit the verified M06 files.
