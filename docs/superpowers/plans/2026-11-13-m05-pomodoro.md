# M05 Recoverable Pomodoro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deadline-based Pomodoro state machine that persists its current session, recovers interruptions as paused, and awards a completed focus phase exactly once.

**Architecture:** Core owns configuration validation, transitions, snapshots, and orchestration. Infrastructure persists one session aggregate plus the existing profile/reward ledger in a single EF Core transaction. A session snapshots configuration at creation and moves through Focus, ShortBreak, and LongBreak phases; UI and Windows lifecycle wiring remain for M08/M10.

**Tech Stack:** C# 14, .NET 10, EF Core 10, SQLite, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-11-easy-to-do-list-design.md`

## Global Constraints

- Presets are exactly `15/3/15`, `25/5/20`, and `50/10/25`; all use a long break after four completed focus phases.
- Custom focus is 15–60 minutes; short break is 20–30% of focus; long break is 15–30 minutes, longer than short break; long-break interval is 3 or 4.
- `PlannedEndAtUtc` is the running timer source of truth; `RemainingSeconds` is the persisted interruption checkpoint.
- Focus completion alone earns `EconomyCalculator.CalculatePomodoroReward`; break completion, Skip, and Stop earn nothing.
- Session transition, profile update, and reward ledger insertion commit atomically.
- Recovery converts a persisted Running session to Paused from its last checkpoint and never derives progress from offline wall-clock time.
- No WPF, sound, notification, scheduler, or Windows lifecycle integration in M05.

## Review Focus

- A command at the exact planned end must complete the phase once, not leave one second or double-reward.
- Repeated Tick calls and process recovery must not create duplicate reward transactions.
- Configuration changes after Start must not alter the active session snapshot.
- Skip behavior differs by phase: skipped Focus terminates unrewarded; skipped Break advances to an awaiting Focus.
- Failed SQLite save must roll back session, profile, and ledger together and leave the service reusable.
