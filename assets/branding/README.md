# EasyToDoList branding

- `easytodolist-logo.png`: ảnh người dùng cung cấp ngày 18/11/2026 từ `Logo_EasyToDoList.png`, giữ nguyên pixel và alpha (500×500).
- `easytodolist.ico`: chuyển từ PNG trên, chứa PNG frames 16, 24, 32, 48, 64, 128 và 256 px cho executable, WPF window/taskbar và tray. Không có thiết kế hay nội dung mới.

Header hiển thị PNG trong vùng 52×52 DIP; dùng file ICO cho các biểu tượng Windows. Icon tray được clone từ embedded resource và giải phóng cùng NotifyIcon.
